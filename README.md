# Zoiko Rooms RAG Assistant

A retrieval-augmented Q&A bot over https://zoikorooms.com, with answers generated by an LLM on Groq.

## RAG pipeline

| Step | Where | What happens |
|---|---|---|
| 1. Load | `ingest.py` | Crawl every page in the site's `sitemap.xml` |
| 2. Split | `ingest.py` | Strip nav/header/footer, split text into ~1000-char overlapping chunks |
| 3. Embed | `ingest.py` | Embed chunks locally with `BAAI/bge-small-en-v1.5` (fastembed) |
| 4. Store | `ingest.py` | Save `data/chunks.json` + `data/vectors.npy` |
| 5. Retrieve | `rag.py` | Embed the question, take the top 5 chunks by cosine similarity (≥ 0.6) |
| 6. Augment | `rag.py` | Insert those chunks into the prompt as context |
| 7. Generate | `rag.py` | Stream an answer from Groq (`openai/gpt-oss-120b`), citing source URLs |

## Setup
```bash
pip install -r requirements.txt
copy .env.example .env     # then put your key in .env:  GROQ_API_KEY=gsk_...
python ingest.py           # steps 1-4; re-run whenever the website changes
```
Get a key at https://console.groq.com/keys. Set `GROQ_MODEL` in `.env` to use a different Groq model.

## Run
```bash
python app.py              # web chat UI -> http://localhost:8080 (set PORT in .env to change)
python rag.py              # or: terminal chat
```

## Project layout
```
ingest.py          steps 1-4: crawl, split, embed, store
rag.py             steps 5-7: retrieve, augment, generate (also a terminal chat)
app.py             FastAPI server: serves the frontend + POST /api/chat (streams NDJSON)
static/index.html  chat page
static/style.css   styling (light/dark, mobile-friendly)
static/script.js   sends questions, renders the streamed answer and sources
data/              generated index (chunks.json, vectors.npy)
```
